# 🌿 Aproveita

> Um marketplace web focado no combate ao desperdício de alimentos, conectando estabelecimentos locais a consumidores em busca de preços acessíveis.

---

## 🚀 Sobre o Projeto

O **Aproveita** nasceu do propósito de unir sustentabilidade e economia local. A plataforma permite aos utilizadores encontrar refeições e alimentos de alta qualidade que seriam desperdiçados pelos estabelecimentos ao final do dia, oferecendo-os com descontos imperdíveis.

Vale ressaltar que este é um projeto no inicio do desenvolvimento e é exclusivamente com a finalidade de praticar e aperfeiçoar competências de desenvolvimento front-end (com abordagem *mobile-first*), não possuindo fins comerciais.

---

## ✨ Funcionalidades

- **📱 Design Mobile-First & Responsivo:** Interface projetada primariamente para dispositivos móveis, oferecendo navegação fluida em qualquer tamanho de ecrã.
- **🔍 Busca Rápida de Alimentos:** Barra de pesquisa acessível tanto no cabeçalho quanto na seção principal (Hero).
- **🏷️ Ofertas em Destaque (Carrossel Horizontal):** Fita de rolagem lateral nativa para cards de produtos com cálculo visual de desconto e localização.
- **🌱 Vantagens em Destaque:** Selos visuais destacando preços baixos, redução de desperdício e incentivo ao comércio local.
- **🎨 Identidade Visual Única:** Paleta de cores aconchegante em tons de Bordô (`#842F3A`) e Creme (`#F7F1E7`), tipografia Poppins e componentes arredondados.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído focando em performance, boas práticas de código e semântica web:

- **HTML5** (Estruturação semântica e acessível)
- **CSS3 & Bootstrap 5** (Sistema de layout responsivo, utilitários Flexbox e estilização customizada)
- **Bootstrap Icons** (Iconografia leve e responsiva)
- **JavaScript (Vanilla)** (Interatividade nativa da aplicação)

## 💻 Como Executar Localmente

Se quiser clonar e testar o projeto no seu computador, siga os passos abaixo:

1. Clone este repositório:
   ```bash
   git clone https://github.com/seu-usuario/aproveita.git
   ```

2. Navegue até a pasta do projeto:
   ```bash
   cd aproveita
   ```

3. Abra o ficheiro `index.html` no seu navegador ou utilize a extensão **Live Server** no VS Code.
